①手機怎麼拿到遊戲

你 push 到 main，GitHub Pages 就上線。手機上的 app 每次請求都先經過 sw.js：有網路就抓最新版並順手存一份，斷網時才拿那份快取出來。遊戲本身只用瀏覽器內建的四樣東西。

②一個檔案裡的分區

4199 行裡，三大陸的題目資料就佔了六成。加內容只動中間那三段，引擎幾乎不用碰。

③題目資料怎麼變成關卡

寫內容的人只用幾個小函式一行一字地填。載入時跑一次索引 pass，自動補上每區的魔王戰、建好查表，並在每個字身上蓋出身章節的戳記，戰鬥和複習本都靠這些戳記運作。

④九個畫面之間怎麼走

所有切換都經過同一個 go(id)。箭頭上是觸發切換的函式。

⑤一場戰鬥的迴圈

怪物的 HP 就是題數，你的心是容錯次數。答對讓怪物掉血，答錯或超時讓你掉心，那個字還會排回隊尾再考一次。

⑥一個字從學會到畢業

戰鬥裡遇過的字都會進複習本。下圖是每次都答對的最快路線，橫軸照實際天數畫：連續答對六次、跨越 29 天才畢業。中途任何一次答錯，那個字就掉回第 0 盒，當天再考。

⑦解鎖規則與存檔

解鎖

  • 章節：通過前一章才開。陣列裡的位置就是解鎖順序。
  • 魔王戰：通關該區全部非魔王章節。
  • 區域：前一區通關半數章節。
  • EXP、等級、武器三大陸共用；章節進度各自記錄。

存檔 kawaii_quest_save_v1

{ exp,
  clears:   { 章節id: 星數 },
  nextBuff, // 下一場的祝福
  srs:      { 大陸|字|中文: {box,due,miss,cid,w} },
  srsDone   // 已畢業字數
}

改了字的寫法或中文，等於換了 key，舊的複習紀錄會被略過，不會壞檔。iOS 主畫面 app 與 Safari 存檔不相通，用「💾 備份／還原」搬。
